About this layout

This page is built only with <div> elements and CSS floats. There is no flexbox and no grid here. The menu on the left is floated to the left side, the content block is floated to the right, and an empty block with the class clear stops the floating before the footer.

Each section has its own background colour, padding, border and a soft box-shadow, so the blocks are easy to tell apart. On screens narrower than 600 pixels the floats are turned off and the two columns are shown one under another.
