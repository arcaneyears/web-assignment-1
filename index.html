About me

Hello! My name is Yersaiyn and I study Software Engineering. This page is my very first assignment in web development, and everything you see here is written by hand in a single HTML file with one stylesheet attached to it.

I like the fact that the web is one of the few platforms where you can write a few lines of text, open a browser, and immediately see the result. There is no long build step between an idea and something you can click on, which makes experimenting cheap and learning fast.

Outside of studying I play chess, read about design, and slowly work through a list of small side projects that I keep in my notes app. Feel free to look around the links below.

What I learned in this task

  1. How to structure a document with semantic HTML tags.
  2. How to link an external stylesheet to an HTML page.
  3. How the box model works — margin, padding and borders.
  4. How element, class and ID selectors differ in specificity.
  5. How to make a layout adapt to small screens with media queries.
