Task 1 — Introduction to HTML & CSS

A personal page with a heading, three paragraphs, an ordered list of five items, unordered lists, a portrait image with an alt attribute and several links. A profile card shows the photo, name, group and a short description.

CSS used

  • Element selector body sets the background colour, font family and size.
  • Class selector .card adds padding, border and rounded corners.
  • ID selector #page-title underlines the main heading.
  • The image uses border-radius: 50%, object-fit: cover and a fixed size.
  • a:hover changes link colour and adds an underline.
  • A media query rearranges the profile card on screens under 600 px.

Task 2 — Simple webpage layout

The page is divided into a header, a navigation bar with four links, a sidebar, a main content block and a footer. The layout uses only div elements and floats; neither flexbox nor grid appears in task2.css.

CSS used

  • .sidebar { float: left; width: 28%; } — the left column.
  • .aside { float: right; width: 68%; } — the right column.
  • .clear { clear: both; } — an empty block that ends the floating so the footer stays at the bottom.
  • Each section has its own background colour, padding, border and box-shadow.
  • Below 600 px the floats are switched off and the columns stack.

Task 3 — Tribute page

A tribute page about Nikola Tesla, placed in the folder exercise1. It contains a heading, a subheading, a summary paragraph, an ordered list of six events, an unordered list of inventions, a portrait and three external links, one of which is styled as a button.

CSS used

  • Two fonts loaded from Google Fonts: Playfair Display for headings and Roboto for body text.
  • A vertical linear-gradient as the page background.
  • .content { max-width: 760px; margin: 0 auto; } centres the text column.
  • The portrait uses max-width, border-radius, box-shadow and a white border.
  • Lists use list-style-type: upper-roman and square.
  • The .btn link changes colour on hover.

Task 4 — Table and form

The page shows a grade table and a feedback form. The table has three columns and four data rows; one name cell is merged with rowspan="2" because the student has two subjects, and the footer merges two cells with colspan="2".

CSS used — table

  • border-collapse: collapse so neighbouring cells share one border.
  • A background colour on th, borders and padding on every cell, text centred.
  • tbody tr:nth-child(even) gives alternating row colours.
  • tr.highlight-row marks one row in yellow. It is written with the element name in front so that its specificity (0,1,1) is not lower than the nth-child rule above it.
  • The heading above the table is styled through the ID #table-heading.

CSS used — form

  • The form has a fixed width of 380 px and margin: 0 auto.
  • Background colour, padding and border-radius: 12px on the container.
  • Labels are bold; inputs, the dropdown and the textarea share the same width and spacing.
  • The submit button has a background colour, rounded corners and a hover effect.
  • The page uses the ID #feedback-form and the class .feedback.

Conclusion

While working on this assignment I practised the structure of an HTML document, the three kinds of CSS selectors and the difference in their specificity, the box model, floats and positioning, styling of tables and forms, and making a layout adapt to small screens with media queries.
